# Karanam Kartikeya — Personal Portfolio

A personal profile website built using HTML and CSS for the **Create and Host a Personal Profile Page** assignment.

The design uses a warm ivory background, orange accents, clear typography, and responsive layouts.
**live link:** https://kartikeyakaranam.github.io/ProfilePage/
## About Me

I’m Karanam Kartikeya, pursuing a **B.Tech in Information Technology at Manipal Institute of Technology (2024–2028)**. My interests include software development, cybersecurity, and algorithmic problem-solving.

## Website Sections

- Introduction and profile photograph
- About Me
- Education and relevant coursework
- Selected projects
- Technical skills
- Interests and current learning
- Contact details and profile links

## Featured Projects

- **Hotel Management System:** Java, JavaFX, PostgreSQL, and JDBC.
- **Path-Planning Research:** Comparison of search algorithms in dynamic grid environments.
- **Amazon Clone:** Responsive e-commerce frontend with a persistent shopping cart.
- **Network Port Scanner:** Multithreaded TCP port scanner built with Python.

## Technologies Used

- HTML5 for semantic page structure
- CSS3 for styling and layout
- Flexbox and CSS Grid
- Media queries for responsive design

The portfolio itself uses no JavaScript, frameworks, or external dependencies.

## Run Locally

1. Download or clone this repository.
2. Open `index.html` in a web browser.

Keep the stylesheet and assets folder in their original locations. No installation or build step is required.
